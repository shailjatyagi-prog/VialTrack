# VialTrack

### Laboratory Sample Organization and Retrieval System

## Project Goal

VialTrack is a web-based laboratory inventory management system designed to simplify the organization, tracking, and retrieval of laboratory samples. Inspired by challenges I learned about during my visit to the Cytokinetics laboratory in California, the project aims to make locating and managing large quantities of laboratory samples more efficient.

## MVP Scope

The minimum viable product (MVP) will include:

- **Sample Registration:** Register samples with unique IDs, sample types, and descriptions.
- **Storage Organization:** Assign samples to specific locations using a hierarchy of incubators, shelves, racks, boxes, and positions.
- **Sample Search and Retrieval:** Search for samples using their unique IDs and retrieve their recorded storage locations.
- **Inventory Management:** Edit, update, and remove existing sample records.
- **Inventory Display:** View registered samples in an organized list or table.

## Future Plans

Potential features for future versions include:

- Sample movement history to track changes in storage locations.
- Bulk sample import through CSV files.
- Inventory analytics and storage capacity statistics.
- Advanced search and filtering options.
- Exportable inventory reports.

**Data Storage:**

**External Data Sources:**
- No external APIs required.
- Synthetic sample data will be used for testing.

## How It Works

Users interact with VialTrack through a web interface built with HTML and CSS. Flask connects the interface to the Python backend, which handles sample registration, storage organization, searching, and inventory management. Sample records are saved and retrieved from a plain text file.
